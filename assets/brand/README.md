# Glyph Brand Assets

This folder stores the project-level PNG logo assets for Glyph / Glyph-27M.

- `glyph_logo.png`: original compact mark.
- `glyph_logotext.png`: original full logo lockup with the Glyph wordmark.
- `glyph_mark.png`: cropped compact mark for favicon, dashboard header, and small UI placements.
- `glyph_wordmark.png`: cropped full logo lockup for documentation or previews.

The dashboard currently serves copies from `web/assets/` so the stdlib HTTP server can expose them under `/assets/...`.
